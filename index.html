01 — Sobre mim

Da operação para
dados e tecnologia.

Sou Leonardo Sousa, estudante de Sistemas de Informação pela UNIP e profissional em transição para a área de dados, BI e tecnologia. Minha trajetória começou na prática — acompanhando indicadores operacionais, validando informações, organizando fluxos e apoiando decisões em ambientes de alta demanda.

Essa experiência me deu uma perspectiva valiosa: entendo processos de dentro para fora. Hoje, aplico esse olhar prático combinado a habilidades em SQL, Python, Power BI e análise de dados para transformar informações brutas em insights que geram eficiência real e apoiam decisões estratégicas.

Meu objetivo é contribuir com equipes que usam dados e tecnologia para resolver problemas reais de negócio — seja em analytics, BI, automação de processos ou melhoria contínua.

02 — Projetos

Estudos de caso
e projetos práticos.

Projetos que combinam análise de dados, automação e visão de processos para resolver problemas reais.

📦
Power BISQLExcel

Dashboard Operacional de Logística

Visualização de KPIs de entrega, volumes, rotas e prazos para apoio à tomada de decisão operacional em tempo real.

Problema

Ausência de visibilidade centralizada sobre indicadores de desempenho operacional — gestores tomavam decisões sem dados consolidados.

Solução

Estruturação de base de dados, tratamento de informações e criação de dashboard interativo com filtros por região, período e operador.

Resultado

Redução do tempo de análise operacional e identificação proativa de gargalos, apoiando ajustes de rota e melhoria no SLA.

🐍
PythonPandasAutomação

Automação de Relatórios com Python

Script de automação para limpeza, padronização e geração de relatórios a partir de bases de dados exportadas de sistemas operacionais.

Problema

Processo manual e repetitivo de tratamento de planilhas consumia horas semanais da equipe, com alto risco de erros humanos.

Solução

Desenvolvimento de pipeline em Python com Pandas para leitura, limpeza, validação e exportação automatizada dos dados consolidados.

Resultado

Eliminação de retrabalho e redução drástica no tempo de geração dos relatórios, com maior confiabilidade das informações.

🗄️
SQLBD RelacionalETL

Análise e Mapeamento de Banco de Dados

Mapeamento, documentação e organização de estrutura de banco de dados relacional para suporte a sistemas de gestão de eventos.

Problema

Banco de dados sem documentação adequada, com inconsistências de dados e dificuldade de manutenção por novos membros da equipe.

Solução

Auditoria completa das tabelas, normalização de dados, criação de dicionário de dados e consultas SQL otimizadas para operações críticas.

Resultado

Melhoria na integridade dos dados, redução de incidentes sistêmicos e documentação clara para manutenção futura do banco.
